# P2 테스트 계획서

## 1. 프로젝트 소개

**StockClass**는 주식, 암호화폐, ETF 등 투자 관련 강의를 제공하는 온라인 교육 플랫폼입니다.
이 문서는 백엔드 서버(API)가 올바르게 동작하는지 확인하기 위한 테스트 계획을 담고 있습니다.

---

## 2. 테스트 목적

- 각 기능이 설계한 대로 정상적으로 동작하는지 확인
- 잘못된 입력이나 권한이 없는 사용자가 접근했을 때 적절히 거부하는지 확인
- 회원(학생/강사)별 권한이 올바르게 분리되어 있는지 확인

---

## 3. 사용자 유형

| 역할 | 설명 |
|------|------|
| **학생 (STUDENT)** | 강의를 검색하고 수강하는 일반 사용자 |
| **강사 (TEACHER)** | 강의를 만들고 관리하는 사용자 |
| **비로그인 사용자** | 로그인 없이 강의 목록만 볼 수 있는 사용자 |

---

## 4. 테스트 방법

- **도구**: Postman (API 요청 테스트 도구)
- **환경**: 로컬 서버 (`http://localhost:8080`)
- **인증 방식**: 로그인 후 발급된 `accessToken`을 `Authorization: Bearer {token}` 헤더에 넣어 전달

## 5. 테스트 범위 및 케이스

### 5-1. 인증 (로그인 / 회원가입)

> 관련 API 경로: `/api/auth`

#### 회원가입 (`POST /api/auth/signup`)

| # | 테스트 내용 | 입력 예시 | 기대 결과 |
|---|------------|----------|----------|
| 1 | 정상 회원가입 (학생) | email, password, nickname, role=STUDENT | 201 Created, 회원 정보 반환 |
| 2 | 정상 회원가입 (강사) | email, password, nickname, role=TEACHER | 201 Created, 회원 정보 반환 |
| 3 | 이미 쓴 이메일로 가입 시도 | 기존 가입자 이메일 | 409 Conflict, "이미 사용 중인 이메일" 오류 |
| 4 | 이메일 없이 가입 시도 | email 필드 빈 값 | 400 Bad Request, 유효성 오류 |
| 5 | 비밀번호 없이 가입 시도 | password 필드 빈 값 | 400 Bad Request, 유효성 오류 |

#### 로그인 (`POST /api/auth/login`)

| # | 테스트 내용 | 입력 예시 | 기대 결과 |
|---|------------|----------|----------|
| 1 | 정상 로그인 | 올바른 email, password | 200 OK, accessToken/refreshToken 반환 |
| 2 | 존재하지 않는 이메일 | 미가입 email | 401/404 오류 |
| 3 | 비밀번호 틀림 | 올바른 email + 틀린 password | 401 Unauthorized, "비밀번호 불일치" 오류 |

#### 토큰 갱신 (`POST /api/auth/refresh`)

| # | 테스트 내용 | 입력 예시 | 기대 결과 |
|---|------------|----------|----------|
| 1 | 정상 토큰 갱신 | 유효한 refreshToken | 200 OK, 새 토큰 반환 |
| 2 | 만료된 토큰으로 요청 | 만료된 refreshToken | 401 Unauthorized |
| 3 | 토큰 없이 요청 | 빈 값 | 400 Bad Request, "Refresh Token 필요" 오류 |

#### 이메일 중복 확인 (`GET /api/auth/check-email?email=...`)

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 이미 사용 중인 이메일 | `true` + "이미 사용 중" 메시지 |
| 2 | 사용 가능한 이메일 | `false` + "사용 가능" 메시지 |

### 5-2. 강의 (Course)

> 관련 API 경로: `/api/courses`

#### 강의 목록 조회 (`GET /api/courses`)

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 비로그인 상태에서 강의 목록 조회 | 200 OK, 강의 목록 반환 |
| 2 | 기본 호출 (파라미터 없음) | 최대 100개의 강의 반환 |
| 3 | `?page=0&size=5` 파라미터 전달 | 5개씩 페이지네이션된 결과 |

#### 강의 상세 조회 (`GET /api/courses/{courseId}`)

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 존재하는 강의 ID 조회 | 200 OK, 강의 상세 반환 |
| 2 | 존재하지 않는 ID 조회 | 404 Not Found |

#### 강의 검색 (`GET /api/courses/search?keyword=주식`)

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 키워드로 검색 | 해당 키워드가 제목에 포함된 강의 목록 |
| 2 | 카테고리 필터 (`?category=CRYPTO`) | 해당 카테고리 강의만 필터링 |
| 3 | 키워드 없이 호출 | 전체 강의 목록 반환 |
| 4 | 결과 없는 키워드 검색 | "검색 결과가 없습니다" 메시지 |

#### 카테고리별 조회 (`GET /api/courses/category/{category}`)

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 유효한 카테고리 (예: `DOMESTIC_STOCK`) | 해당 카테고리 강의 목록 |
| 2 | 잘못된 카테고리 이름 | 400 Bad Request 또는 빈 목록 |

> **지원 카테고리**: `DOMESTIC_STOCK` (국내 주식), `OVERSEAS_STOCK` (해외 주식), `CRYPTO` (암호화폐), `NFT`, `ETF`, `FUTURES` (선물투자)

#### 강의 등록 (`POST /api/courses`) — 강사 전용

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 강사 계정으로 강의 등록 | 201 Created, 강의 정보 반환 |
| 2 | 학생 계정으로 강의 등록 시도 | 403 Forbidden, 권한 없음 |
| 3 | 비로그인 상태에서 강의 등록 시도 | 401 Unauthorized |
| 4 | 제목 없이 등록 시도 | 400 Bad Request, 유효성 오류 |

#### 강의 수정 (`PUT /api/courses/{courseId}`) — 강사 전용

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 본인 강의 수정 | 200 OK, 수정된 강의 반환 |
| 2 | 다른 강사의 강의 수정 시도 | 403 Forbidden |

#### 강의 삭제 (`DELETE /api/courses/{courseId}`) — 강사 전용

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 본인 강의 삭제 | 200 OK |
| 2 | 다른 강사의 강의 삭제 시도 | 403 Forbidden |

### 5-6. 강사 전용 — 파일 업로드

> 관련 API 경로: `/api/v1/teacher/uploads`

> **흐름 설명**: 강의 영상과 썸네일은 서버에 직접 올리지 않고, `presigned URL`(임시 업로드 주소)을 받아서 클라우드(Cloudflare R2 `stockclass` 버킷)에 직접 업로드하는 방식입니다. 영상은 `lectures/{id}/` 폴더, 썸네일은 `courses/{id}/` 폴더에 저장됩니다.

| # | 테스트 내용 | 기대 결과 |
|---|------------|----------|
| 1 | 영상 업로드 URL 발급 (`POST /video-presigned`) | 200 OK, 업로드용 임시 URL 반환 |
| 2 | 영상 업로드 확인 (`POST /video-confirm`) | 200 OK, 업로드 완료 확인 |
| 3 | 썸네일 업로드 URL 발급 (`POST /thumbnail-presigned`) | 200 OK, 임시 URL 반환 |
| 4 | 썸네일 업로드 확인 (`POST /thumbnail-confirm`) | 200 OK, 완료 확인 |
| 5 | 학생 계정으로 접근 | 403 Forbidden |

|------|------|
