### 2.1 업로드 API

#### 1) Pre-signed URL 발급 (동영상)

```http

Content-Type: application/json

{
  "fileName": "lecture-intro.mp4",
  "fileSize": 1073741824,
  "mimeType": "video/mp4"
}
```

**Response (200 OK)**
```json
{
```

## 3. 데이터베이스 스키마 (5주차 이후)

### 3.1 신규 테이블: VIDEO_UPLOAD

```sql
CREATE TABLE video_upload (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    lecture_id BIGINT NOT NULL UNIQUE COMMENT '강의 ID (1:1 관계)',
    r2_object_key VARCHAR(500) NOT NULL COMMENT 'R2 버킷 내 파일 경로',
    original_filename VARCHAR(255) NOT NULL COMMENT '원본 파일명',
    file_size BIGINT NOT NULL COMMENT '파일 크기(bytes)',
    content_type VARCHAR(50) COMMENT 'MIME 타입 (video/mp4 등)',
    upload_status ENUM('PRESIGNED', 'UPLOADED', 'CONFIRMED') DEFAULT 'PRESIGNED' COMMENT '업로드 상태',
    upload_started_at TIMESTAMP NULL COMMENT '업로드 시작 시간',
    upload_completed_at TIMESTAMP NULL COMMENT '업로드 완료 시간',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_video_upload_lecture FOREIGN KEY (lecture_id) REFERENCES lecture(id) ON DELETE CASCADE,
    UNIQUE INDEX idx_lecture_id (lecture_id)
) ENGINE=InnoDB CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 3.2 기존 테이블 변경

#### COURSE 테이블
```sql
ALTER TABLE course 
ADD COLUMN is_published BOOLEAN DEFAULT FALSE COMMENT '강의 공개 여부',
ADD COLUMN published_at TIMESTAMP NULL COMMENT '공개 시간',
ADD INDEX idx_instructor_published (instructor_id, is_published);
```

#### LECTURE 테이블
```sql
ALTER TABLE lecture 
ADD COLUMN upload_status ENUM('PENDING', 'UPLOADING', 'COMPLETED', 'FAILED') DEFAULT 'PENDING' COMMENT '업로드 상태',
ADD INDEX idx_upload_status (upload_status);
```

#### LECTURE_PROGRESS 테이블
```sql
ALTER TABLE lecture_progress 
ADD COLUMN is_completed BOOLEAN DEFAULT FALSE COMMENT '해당 영상 완료 여부';
```

## 6. 향후 개선 사항

### 6.1 6주차 이후 (Phase 3 이상)

- **실시간 기능**: WebSocket으로 수강자의 진도율 실시간 업데이트
- **영상 통계**: 각 영상별 평균 시청 시간, 드롭아웃 지점 분석
- **강사 공지사항**: 강의별 공지사항 기능
- **다운로드 기능**: 강의자가 수강자 목록 및 통계를 CSV로 다운로드
- **영상 편집**: 프리뷰, 자막 추가 등 간단한 영상 편집 기능

### 6.2 성능 최적화

- **이미지 최적화**: 썸네일 자동 리사이징 (WebP 변환)
- **캐싱 전략**: Redis 도입하여 대시보드 데이터 캐싱
- **배치 처리**: 진도율 계산을 배치로 처리
- **CDN 최적화**: Cloudflare 캐시 정책 세분화

### 6.3 보안 강화

- **Rate Limiting**: 업로드 API에 대한 속도 제한
- **파일 검증**: 동영상/이미지 파일 무결성 검증
- **감시**: 악의적인 강의자 감시 및 차단 시스템

## 10. 문제 해결 및 FAQ

### Q1. 대용량 파일 업로드 시 시간 초과 문제는?
**A.** Pre-signed URL 방식으로 클라이언트가 직접 R2에 업로드하므로 서버 시간 초과 없음. URL 유효시간만 충분히 설정하면 됨.

### Q2. 영상 처리 (트랜스코딩)는 계획에 없나?
**A.** P2는 원본 그대로 저장. 향후 Cloudflare Stream 또는 AWS MediaConvert 연동으로 트랜스코딩 추가 가능.

### Q3. 동영상 재생 시 DRM(저작권 보호)은?
**A.** 현재 R2 공개 URL로 제공. 필요 시 signed URL 또는 Cloudflare Stream의 DRM 기능 활용.

### Q4. 수강생이 영상을 다운로드할 수 있나?
**A.** 현재는 스트리밍만 지원. 다운로드 방지 또는 제한은 별도 정책 수립 필요.
