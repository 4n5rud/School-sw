# [P2] StockFlow 아키텍처 설계서

> **목표**: 강의자 콘텐츠 파이프라인 — BE/FE/Cloudflare R2 연동 구조 및 레이어별 책임 정의

---

## 1. 전체 시스템 구성

```
┌─────────────────────────────────────────────────────────────────┐
│                        강의자 브라우저                           │
│  Next.js (App Router) — /teacher/* 라우트                        │
└────────────┬───────────────────────────────┬────────────────────┘
             │ REST API                       │ PUT (Pre-signed URL)
             ▼                               ▼
┌────────────────────────┐       ┌────────────────────────────────┐
│   Spring Boot BE        │       │        Cloudflare R2            │
│   (Java 21, Gradle)     │◄──────│  stockflow-videos  (Private)    │
│   /api/v1/teacher/**   │       │  stockflow-thumbnails (Public)  │
└────────────┬───────────┘       └───────────────┬────────────────┘
             │ JPA                               │ CDN
             ▼                                  ▼
┌────────────────────────┐       ┌────────────────────────────────┐
│      MySQL DB           │       │     수강생 브라우저 (스트리밍)   │
│  (P1 스키마 + P2 확장)   │       │  GET https://pub-xxx.r2.dev/…  │
└────────────────────────┘       └────────────────────────────────┘
```

## 3. R2 연동 아키텍처 (Pre-signed URL 패턴)

```
강의자                  BE                     R2
  │                      │                      │
  │──POST video-presigned→│                      │
  │                      │──generatePresignedUrl→│
  │                      │←── uploadUrl ─────────│
  │←── uploadUrl ─────────│                      │
  │                      │                      │
  │──PUT uploadUrl (직접)──────────────────────→ │
  │←── 200 OK ───────────────────────────────── │
  │                      │                      │
  │──POST video-confirm──→│                      │
  │                      │──verifyObject()──────→│
  │                      │←── metadata ──────────│
  │                      │ lecture.videoUrl 저장  │
  │←── { videoUrl } ──────│                      │
```

**핵심**: 동영상 파일이 BE 서버를 **거치지 않음** → 서버 부하 제거, 대용량 처리 가능

### 3.1 버킷 구성

| 버킷 | 접근 방식 | 용도 |
|:---|:---:|:---|
| `stockflow-videos` | Private (Pre-signed URL) | 강의 영상 원본 |
| `stockflow-thumbnails` | Public CDN | 강의 썸네일 이미지 |

### 3.2 객체 키 규칙

```
영상:     lectures/{lectureId}/{uuid}.mp4
썸네일:   courses/{courseId}/thumbnail.{jpg|png|webp}
```

## 4. 프론트엔드 라우팅 구조

```
/teacher
├── /dashboard              ← 강의자 홈 (통계 카드 + 강의 목록)
├── /courses
│   ├── /new                ← 강의 생성 폼
```

## 5. 데이터베이스 스키마 변경 (P1 → P2)

| 테이블 | 변경 유형 | 변경 내용 |
|:---|:---:|:---|
| `course` | ALTER | `is_published BOOLEAN DEFAULT FALSE` 추가 |
| `lecture` | ALTER | `upload_status VARCHAR(20) DEFAULT 'PENDING'` 추가 |
| `lecture_progress` | ALTER | `is_completed BOOLEAN DEFAULT FALSE` 추가 |
| `video_upload` | CREATE | 신규 테이블 (R2 메타데이터) |

```yaml

  account-id:         ${CF_ACCOUNT_ID}
  access-key-id:      ${CF_R2_ACCESS_KEY}

  thumbnail-bucket:   stockflow-thumbnails

```

## 7. 보안 아키텍처

| 위협 | 대응 |
|:---|:---|
| Pre-signed URL 재사용 | 유효시간 1시간 제한 |
| 허용되지 않은 파일 형식 | Content-Type 화이트리스트 (video/mp4, video/webm) |
| 용량 초과 업로드 | `ContentLengthRange` 최대 5GB 제한 |
| 타 강의자 파일 접근 | objectKey에 lectureId + UUID 포함, 소유권 검증 |
| 비인가 영상 스트리밍 | 영상 버킷 Private + 수강 여부 확인 후 Signed URL 발급 |
