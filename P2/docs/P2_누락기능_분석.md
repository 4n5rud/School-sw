## 우선순위 제안

1. 강의 진도율 저장 및 완료 체크 UI
2. 수강 완료 처리 버튼 연결

4. 모바일 반응형 플레이어

7. 전체 수강률 / 수료증

### 🟢 낮음 (추가 기능)
