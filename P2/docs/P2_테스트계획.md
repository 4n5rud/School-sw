# [P2] StockFlow 테스트 계획서

> **목적**: P2에서 새로 구현된 강의자 API 및 기존 P1 API 회귀 테스트  
> **테스트 방법**: Swagger UI (`http://localhost:8080/swagger-ui.html`) 또는 Postman

---

## 1. 테스트 환경

| 항목 | 값 |
|:---|:---|
| 서버 URL | `http://localhost:8080` |
| DB | MySQL 8 (`stock_class`) |
| 인증 방식 | JWT Bearer Token (`Authorization: Bearer {token}`) |
| Content-Type | `application/json` |

> **R2 주의**: `application.yml`의 Cloudflare R2는 더미값으로 설정됨.  
> TC-UPLOAD-01~07 실제 R2 연동 테스트는 실제 키 교체 후 수행.

## 4. 강의자 강의 관리 API (`/api/v1/teacher/courses`)

### 사전 조건: TEACHER 토큰 사용

| TC-ID | 시나리오 | Method + Path | 기대 HTTP | 검증 포인트 |
|:---:|:---|:---|:---:|:---|
| TC-COURSE-01 | 내 강의 목록 조회 (초기) | GET `/api/v1/teacher/courses` | 200 | 빈 배열 반환 |
| TC-COURSE-02 | 강의 생성 성공 | POST `/api/v1/teacher/courses` | 201 | `isPublished: true`, `studentCount: 0` |
| TC-COURSE-03 | STUDENT 권한으로 강의 생성 시도 | POST `/api/v1/teacher/courses` | 403 | Forbidden 반환 |
| TC-COURSE-04 | 제목 3자 미만 생성 시도 | POST `/api/v1/teacher/courses` | 400 | 검증 오류 메시지 |
| TC-COURSE-05 | 내 강의 목록 조회 (생성 후) | GET `/api/v1/teacher/courses` | 200 | 강의 1개 포함 |
| TC-COURSE-06 | 강의 수정 | PUT `/api/v1/teacher/courses/{id}` | 200 | 수정된 정보 반환 |
| TC-COURSE-07 | 타인 강의 수정 시도 | PUT `/api/v1/teacher/courses/{id}` | 403 | Forbidden |
| TC-COURSE-08 | 강의 공개/비공개 토글 | PATCH `.../publish` | 200 | `isPublished` 반전 |
| TC-COURSE-09 | 강의 삭제 (수강생 없음) | DELETE `/api/v1/teacher/courses/{id}` | 200 | 삭제 완료 메시지 |
| TC-COURSE-10 | 강의 삭제 (수강생 있음) | DELETE `/api/v1/teacher/courses/{id}` | 403 | "수강생이 있는 강의는 삭제할 수 없습니다" |

**TC-COURSE-02 Request Body:**
```json
{
  "title": "주식 입문: 차트 분석 기초",
  "description": "주식 초보자를 위한 차트 분석 완전 정복 강의입니다.",
  "category": "DOMESTIC_STOCK",
  "price": 50000,
  "thumbnailUrl": "https://example.com/thumb.jpg"
}
```

## 5. 섹션 관리 API

| TC-ID | 시나리오 | Method + Path | 기대 HTTP | 검증 포인트 |
|:---:|:---|:---|:---:|:---|
| TC-SEC-01 | 섹션 생성 | POST `/api/v1/teacher/courses/{id}/sections` | 201 | `sortOrder: 1` 자동 부여 |
| TC-SEC-02 | 두 번째 섹션 추가 | POST 위 동일 | 201 | `sortOrder: 2` |
| TC-SEC-03 | 섹션 수정 | PUT `/api/v1/teacher/sections/{id}` | 200 | 제목 변경 확인 |
| TC-SEC-04 | 섹션 순서 일괄 변경 | PATCH `.../sections/reorder` | 200 | sortOrder 변경 확인 |
| TC-SEC-05 | 타인 강의의 섹션 수정 | PUT 위 동일 (타인 토큰) | 403 | Forbidden |
| TC-SEC-06 | 섹션 삭제 | DELETE `/api/v1/teacher/sections/{id}` | 200 | 삭제 완료 |

**TC-SEC-01 Request Body:**
```json
{ "title": "1주차: 주식 기초 이론" }
```

**TC-SEC-04 Request Body:**
```json
{
  "sectionOrders": [
    { "sectionId": 2, "sortOrder": 1 },
    { "sectionId": 1, "sortOrder": 2 }
  ]
}
```

## 7. 영상 업로드 API (`/api/v1/teacher/uploads`)

> 아래 테스트는 실제 Cloudflare R2 키 설정 필요.  
> 더미 환경에서는 TC-UPLOAD-02, 03, 06 (입력값 검증)만 테스트 가능.

| TC-ID | 시나리오 | Method + Path | 기대 HTTP | 검증 포인트 |
|:---:|:---|:---|:---:|:---|
| TC-UPLOAD-01 | 영상 Pre-signed URL 발급 (R2 실제) | POST `.../video-presigned` | 200 | `uploadUrl`, `objectKey`, `expiresAt` 반환. lecture `uploadStatus: PRESIGNED` |
| TC-UPLOAD-02 | 허용 안 된 Content-Type (exe) | POST `.../video-presigned` | 400 | "허용되지 않은 파일 형식입니다" |
| TC-UPLOAD-03 | 5GB 초과 파일 크기 | POST `.../video-presigned` | 400 | "파일 크기는 5GB 이하여야 합니다" |
| TC-UPLOAD-04 | 영상 업로드 완료 확인 (R2 실제) | POST `.../video-confirm` | 200 | `videoUrl` = CDN URL, `uploadStatus: CONFIRMED`, DB videoUrl 저장 |
| TC-UPLOAD-05 | 썸네일 Pre-signed URL 발급 (R2 실제) | POST `.../thumbnail-presigned` | 200 | `uploadUrl`, `objectKey` 반환 |
| TC-UPLOAD-06 | 허용 안 된 이미지 형식 (gif) | POST `.../thumbnail-presigned` | 400 | "허용되지 않은 이미지 형식입니다" |
| TC-UPLOAD-07 | 썸네일 업로드 완료 확인 (R2 실제) | POST `.../thumbnail-confirm` | 200 | course `thumbnailUrl` CDN URL로 업데이트 |

**TC-UPLOAD-01 Request Body:**
```json
{
  "lectureId": 1,
  "filename": "lecture_01.mp4",
  "contentType": "video/mp4",
  "fileSize": 104857600
}
```

**TC-UPLOAD-04 Request Body:**
```json
{
  "lectureId": 1,
  "objectKey": "lectures/1/abc-uuid.mp4",
  "playTime": 600
}
```

### 업로드 상태 전이 검증

| 이벤트 | BE 상태 변화 |
|:---|:---|
| 영상 유닛 생성 | `PENDING` |
| video-presigned 호출 | `PENDING → PRESIGNED` |
| video-confirm 호출 (성공) | `PRESIGNED → CONFIRMED` |
| (FE가 관리) 업로드 진행 중 | `UPLOADING` — BE 미관리, FE에서만 표시 |

## 8. 수강자 분석 API (`/api/v1/teacher`)

### 사전 준비
```
1. TEACHER로 강의 생성
2. TEACHER로 섹션/강의 영상 유닛 추가
3. STUDENT로 수강신청 (POST /api/enrollments)
4. STUDENT로 강의 진도 저장 (POST /api/lecture-progress)
```

| TC-ID | 시나리오 | Method + Path | 기대 HTTP | 검증 포인트 |
|:---:|:---|:---|:---:|:---|
| TC-STAT-01 | 강의자 대시보드 | GET `/api/v1/teacher/dashboard` | 200 | `totalCourses`, `totalStudents`, `completedStudents`, `courses[]` |
| TC-STAT-02 | 강의별 수강자 목록 | GET `/api/v1/teacher/courses/{id}/students` | 200 | `students[].nickname`, `overallProgress`, `enrolledAt` |
| TC-STAT-03 | 영상별 시청 통계 | GET `/api/v1/teacher/courses/{id}/stats` | 200 | `lectureStats[].viewCount`, `completionRate`, `avgWatchPosition` |
| TC-STAT-04 | 타인 강의 수강자 조회 | GET `.../students` (타인 토큰) | 403 | Forbidden |
| TC-STAT-05 | 수강생 없는 강의 통계 | GET `.../students` | 200 | `totalStudents: 0`, `students: []` |

**TC-STAT-01 기대 응답 예시:**
```json
{
  "success": true,
  "data": {
    "totalCourses": 1,
    "totalStudents": 1,
    "completedStudents": 0,
    "courses": [
      {
        "id": 1,
        "title": "주식 입문...",
        "isPublished": true,
        "studentCount": 1
      }
    ]
  }
}
```

## 10. 에러 응답 형식 검증

모든 API의 에러는 아래 일관된 형식으로 반환되어야 합니다:

```json
{
  "success": false,
  "message": "에러 메시지",
  "data": null
}
```

| 상황 | HTTP 코드 |
|:---|:---:|
| 인증 토큰 없음 / 만료 | 401 |
| 권한 없음 (역할 불일치) | 403 |
| 소유권 없음 (타인 리소스 수정) | 403 |
| 리소스 없음 | 404 |
| 잘못된 입력값 (Validation) | 400 |
| 허용되지 않은 파일 형식/크기 | 400 |
| R2 연결 오류 | 500 |

## 11. E2E 통합 테스트 시나리오

### 강의자 전체 흐름 (R2 실제 연동 시)

```
Step 1. TEACHER 로그인 → accessToken 획득
Step 2. 강의 생성  →  courseId 저장
Step 3. 섹션 추가  →  sectionId 저장
Step 4. 영상 유닛 추가  →  lectureId 저장 (uploadStatus: PENDING)
Step 5. video-presigned 호출  →  uploadUrl, objectKey 획득 (uploadStatus: PRESIGNED)
Step 6. 브라우저/Postman에서 PUT uploadUrl로 직접 파일 업로드
Step 7. video-confirm 호출  →  videoUrl 반환 (uploadStatus: CONFIRMED)
Step 8. STUDENT 로그인
Step 9. 강의 수강신청 (POST /api/enrollments)
Step 10. 강의 진도 저장 (POST /api/lecture-progress, isCompleted: true)
Step 11. TEACHER로 전환 → 대시보드 확인 (totalStudents: 1)
Step 12. 강의별 수강자 목록 → overallProgress > 0 확인
Step 13. 강의 공개 토글 → isPublished: false 확인
```
