## 4. R2 설정 (`R2Config.java`)

```java
@Configuration
public class R2Config {

    @Value("${cloudflare.r2.account-id}")
    private String accountId;

    @Value("${cloudflare.r2.access-key-id}")
    private String accessKeyId;

    @Value("${cloudflare.r2.secret-access-key}")
    private String secretAccessKey;

    @Bean
    public S3Client r2Client() {
        return S3Client.builder()
            .endpointOverride(URI.create("https://" + accountId + ".r2.cloudflarestorage.com"))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(accessKeyId, secretAccessKey)))
            .region(Region.of("auto"))
            .build();
    }

    @Bean
    public S3Presigner r2Presigner() {
        return S3Presigner.builder()
            .endpointOverride(URI.create("https://" + accountId + ".r2.cloudflarestorage.com"))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(accessKeyId, secretAccessKey)))
            .region(Region.of("auto"))
            .build();
    }
}
```

public void validateCourseOwner(Long courseId, Long currentUserId) {
    Course course = courseRepository.findById(courseId)
        .orElseThrow(() -> new EntityNotFoundException("강의를 찾을 수 없습니다."));

    if (!course.getInstructorId().equals(currentUserId)) {
        throw new AccessDeniedException("해당 강의에 대한 권한이 없습니다.");
    }
}

## 7. Pre-signed URL 발급 로직

```java
// TeacherUploadService.java
public VideoPresignedResponse generateVideoPresignedUrl(VideoPresignedRequest request, Long currentUserId) {
    // 1. 소유권 검증
    ownershipValidator.validateLectureOwner(request.getLectureId(), currentUserId);

    // 2. Content-Type 화이트리스트 검증
    List<String> allowed = List.of("video/mp4", "video/webm");
    if (!allowed.contains(request.getContentType())) {
        throw new IllegalArgumentException("허용되지 않은 파일 형식입니다.");
    }

    // 3. 파일 크기 검증 (5GB)
    if (request.getFileSize() > 5L * 1024 * 1024 * 1024) {
        throw new IllegalArgumentException("파일 크기는 5GB 이하여야 합니다.");
    }

    // 4. objectKey 생성 (lectureId + UUID)
    String objectKey = "lectures/" + request.getLectureId() + "/" + UUID.randomUUID() + ".mp4";

    // 5. Pre-signed URL 발급
    PutObjectPresignRequest presignRequest = PutObjectPresignRequest.builder()
        .signatureDuration(Duration.ofSeconds(presignedUrlExpiry))
        .putObjectRequest(r -> r
            .bucket(videoBucket)
            .key(objectKey)
            .contentType(request.getContentType())
            .build())
        .build();

    String uploadUrl = r2Presigner.presignPutObject(presignRequest).url().toString();

    // 6. DB 상태 PRESIGNED로 변경
    updateLectureUploadStatus(request.getLectureId(), UploadStatus.PRESIGNED);

    return new VideoPresignedResponse(uploadUrl, objectKey, LocalDateTime.now().plusSeconds(presignedUrlExpiry));
}
```

## 8. 업로드 완료 처리 (`video-confirm`)

```java
public VideoConfirmResponse confirmVideoUpload(VideoConfirmRequest request) {
    // 1. R2에서 파일 존재 확인
    HeadObjectResponse meta = r2Client.headObject(r -> r
        .bucket(videoBucket)
        .key(request.getObjectKey())
        .build());

    // 2. CDN URL 생성
    String videoUrl = publicCdnUrl + "/" + request.getObjectKey();

    // 3. Lecture 업데이트
    Lecture lecture = lectureRepository.findById(request.getLectureId()).orElseThrow();
    lecture.setVideoUrl(videoUrl);
    lecture.setPlayTime(request.getPlayTime());
    lecture.setUploadStatus(UploadStatus.CONFIRMED);
    lectureRepository.save(lecture);

    return new VideoConfirmResponse(lecture.getId(), videoUrl, UploadStatus.CONFIRMED, LocalDateTime.now());
}
```

## 9. 코딩 컨벤션

| 항목 | 규칙 |
|:---|:---|
| 클래스명 | PascalCase |
| 메서드/변수 | camelCase |
| 상수 | UPPER_SNAKE_CASE |
| 패키지 | 소문자, 단수 (`controller`, `service`, `domain`) |
| DTO 네이밍 | `{엔티티}{동작}Request` / `Response` |
| 예외 | `GlobalExceptionHandler`에서 일괄 처리 |
| 로그 | `@Slf4j` 사용, `log.info()` / `log.error()` |

### 예외 처리 원칙

```java
// GlobalExceptionHandler.java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(AccessDeniedException.class)
    public ResponseEntity<ErrorResponse> handleAccessDenied(AccessDeniedException e) {
        return ResponseEntity.status(403).body(new ErrorResponse("FORBIDDEN", e.getMessage()));
    }

    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<ErrorResponse> handleBadRequest(IllegalArgumentException e) {
        return ResponseEntity.status(400).body(new ErrorResponse("BAD_REQUEST", e.getMessage()));
    }
}
```
