### 4.2 서버 상태 → React Query, UI 상태 → useState

```typescript
// 서버 데이터: React Query
const { data: students } = useQuery({
  queryKey: ['course-students', courseId],
  queryFn: () => teacherApi.getCourseStudents(courseId),
});

// 업로드 진행률: 로컬 상태
const [progress, setProgress] = useState(0);
```

### 4.3 업로드 컴포넌트 핵심 로직

```typescript
async function uploadVideo(file: File, lectureId: number) {
  // 1. Pre-signed URL 발급
  const { uploadUrl, objectKey } = await teacherApi.getVideoPresignedUrl({
    lectureId,
    filename: file.name,
    contentType: file.type,
    fileSize: file.size,
  });

  // 2. R2 직접 PUT 업로드
  await axios.put(uploadUrl, file, {
    headers: { 'Content-Type': file.type },
    onUploadProgress: (e) => {
      setProgress(Math.round((e.loaded * 100) / e.total!));
    },
  });

  // 3. 완료 신호
  const { videoUrl } = await teacherApi.confirmVideoUpload({
    lectureId,
    objectKey,
    playTime: await getVideoDuration(file),
  });

  return videoUrl;
}
```

export const teacherApi = {

## 7. 에러 처리 원칙

- **403**: "권한이 없습니다" 토스트 + 대시보드로 리다이렉트
- **400 (파일 형식/크기)**: 업로드 전 클라이언트 사이드 검증으로 사전 차단
- **업로드 실패**: 재시도 버튼 표시, upload_status = FAILED 안내
- **네트워크 오류**: React Query 자동 재시도 3회 후 에러 메시지

### 클라이언트 사이드 파일 검증

```typescript
const ALLOWED_TYPES = ['video/mp4', 'video/webm'];
const MAX_SIZE = 5 * 1024 * 1024 * 1024; // 5GB

if (!ALLOWED_TYPES.includes(file.type)) throw new Error('mp4, webm 파일만 업로드 가능합니다.');
if (file.size > MAX_SIZE) throw new Error('파일 크기는 5GB 이하여야 합니다.');
```
